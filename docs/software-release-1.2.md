# Pseudepigrapha-TF v1.2.0 — converter software

Install the MIT-licensed converter through Agora or from this tagged Python project. Agora acquires OCP directly at `853a64b623de296d2b8532a43593607772e7c45a` and materializes Text-Fabric locally.

- Direct support for the unmodified 2026 OCP source: 66 independent XML documents, 384 textual versions, 84,359 units, 91,501 readings and 61 metadata documents.
- Six compact Greek/Latin editions with explicitly linked editorial English; source-declared generated translations remain separate from historical witnesses.
- Auditable exclusion of derived TEI mirrors and separate ApDan morphology; optional local morphology and clavis lookup helpers.
- Python 3.12+ with clean-wheel tests on Python 3.14; native TF and comparison-browser acceptance.

This is a software release, not a corpus publication. No new OCP editions or generated TF archives are bundled. The existing small historical classification lookup is retained. The historical v1.1.0 data release and its assets remain unchanged. The Agora registry can advance independently after its own review and sandbox acceptance.
